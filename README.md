# distributedcomputing4kids-website
Website for Distributed Computing 4 Kids (and Executives). The book is out
(July 2026), so the site sells rather than teases: primary CTAs point at the
direct store on pigscanfly.ca (direct sales keep the customer relationship),
with the Amazon paperback/Kindle listings as the secondary option, plus the
Spark/Python setup guides for readers working through part two.
